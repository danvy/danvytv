# Alex Danvy personal website

You will find all the source code including all contents, customized components and deployment script.
The stack is pretty simple : [Astro](https://astro.build/) with [Pagefind](https://pagefind.app/) for search, hosted on [GitHub](https://github.com)

The production website and demo is running on [danvy.tv](https://danvy.tv/)

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # type-check and build to dist/
npm run preview  # serve the production build
```
